# Better UIs

Sixty Four 界面模组，清单版本保持 `0.2.0`。官方开发交接见工作区 `Codex-md/progress_BetterUI.md`。

## 桌面 1.3 商店

在 **ModLoader 菜单 → Better UIs（更好的 UI 界面）→ 商店版本** 中选择，点击保存并重载后生效：

- **1.3 商店**：默认选项，首次使用原生分类商店；右下角新增样式按钮，可即时切换原生布局与胶囊分类布局。
- **1.2.1 商店**：经典长列表，右下角可缩小／展开；开启“商店分类”后，另一个右下角按钮可切换八类紧凑视图。分类为空时不显示，未分配建筑进入“其他”。

两种视图均使用游戏 1.3 的商品、价格、解锁和购买逻辑。独立拆除／搬迁按钮保留在经典列表左侧；不恢复旧版拆除商品。设置名中的版本指界面，不会降级游戏或转换存档。

经典商店距窗口右边缘保留 8px，另外固定预留 14px 滚动条区域；分类展开产生滚动时卡片不会变窄。长列表、缩小和紧凑视图共用这一区域，拆除／搬迁按钮同步避让。

分类卡片的图片、价格、数量和说明取自活动 Store；说明复用 ModLoader 的 600 ms Tooltip。紧凑分类偏好沿用本机 `cattailShopCategoriesCompressed`，与世界存档分开。语言重建、现实／虚空切换及 HUD 隐藏／恢复由适配层同步。

商店实现入口按 `classic-shop.js` → `shop-categories.js` → `native-accordion-shop.js` 加载。经典视图移动原生商品卡片并保留其引用与购买事件，通过私有 Symbol 协作；不创建 `game.shop`，不重启遗留 `Shop`，不新增计时循环或另一套存档／价格逻辑。1.3分支不安装经典补丁，经典分支不安装新胶囊入口。

## 1.3 胶囊分类布局

将商店版本设为 **1.3 商店**并重载后，右下角有两个独立按钮：

- **≡：切换商店样式**，在原生侧向卡片与胶囊分类布局间即时切换。
- **¶：隐藏建筑描述**，控制两种1.3布局的全部建筑描述，新解锁建筑也隐藏；图片、名称、价格、数量及新建筑标记继续显示。

首次保持原生布局、显示描述。两项偏好分别保存到本机 `cattailNativeShopStyle`、`cattailNativeShopDescriptionsHidden`，不写入世界存档，不影响经典八类偏好。切换到经典商店仍使用原有设置的保存/重载流程。

胶囊布局保留原生类别、顺序、图标、可见性和真实卡片。悬停任一类别时，所有可见圆形按钮同步用240ms向左扩宽；图标右端不动，两端保持半圆，图标左侧显示当前语言的类别名称，字号在原基准上增加10%，长语言按可用空间适配。胶囊扩宽后与商品卡片同宽。一次向下展开一类，再次点击收起。标题与该类所有商品共用一个半径为原圆钮半径（2em）的裁剪外壳：标题/图标上部固定，底部圆弧随商品高度用240ms向下伸展，收起时反向收回，不做商品淡入淡出。底部两个角与分类下半圆弧同半径，商品零间隔连接、内部用1px细线分隔，细线两端各留1em空隙，与卡片内容的水平留白对齐。类别和展开卡片在同一列滚动，只有最右侧14px滚动区域，距窗口右侧8px；滚动视口延伸至窗口底边，卡片从右下角角落按钮后方经过，按钮自身保持上层可点，容器空白处透明。末尾保留可将最后商品滚到按钮上方的留白。拆除/搬迁收起时回到类别列及原生纵坐标，打开商品时移到卡片左侧，与离屏分类入口位于同一侧。左侧分类按钮组独立垂直居中，不把工具算入居中组；工具以各自原生纵坐标为锚，只有与分类组或相邻工具发生挤压时才用240ms让位。优先向下，下方不足则将前面的工具向上让位，保持拆解/搬迁顺序和间距；空间恢复或全部收起后回原位。右下角开关固定。

全部收起时，类别圆钮的纵坐标与原生居中排列一致，按实际可见类别和工具测量；横向保留滚动条空间。打开或切换分类时，用240ms平滑滚动到屏幕顶部下方8px；尾部按需要补足滚动空间，最后一个或短分类也可置顶。用户滚轮、拖动或触摸滚动可中断自动定位，此后整列自由滚动；全部收起后平滑返回原生起点。

仅在胶囊布局中，Alt+1～7固定打开采集、解构、破坏、转换、存储、特殊、其他。未解锁或当前位面不显示的类别不响应、不重新编号，完成/虚空没有额外数字绑定。已展开类别再次按快捷键只重新置顶，鼠标再次点同类仍可收起。保留原生Alt清晰视图，输入框/可编辑内容、菜单/模态框、隐藏HUD及Ctrl/Shift/Meta额外组合或按键长按重复不触发。通过既有Shortcut API登记本地化类别提示，实际输入仍由本Mod处理。

商品展开期间，当前展开分类的黄色圆形入口始终保留在卡片左侧，无论标题完全可见、部分可见或已经离屏；复用该类原有左侧按钮及槽位，不创建第二个重叠目标。其他分类仍只有标题完全离开商店可视区域上方或下方时显示，未解锁/位面隐藏类不加入。全部收起后左栏清空。左侧分类按钮组始终以屏幕垂直中线居中，增减成员时其余按钮用240ms重新排布。每个入口从自己的标题图标实际位置滑到左侧槽位，非当前分类的原标题重现后再滑回该图标；使用横纵双轴位移，返回目标随滚动更新，中途反向从当前动画位置续接。当前展开分类保留标题原图标，左侧为额外入口；其他分类的主图标在代理离开期间隐藏，归位后恢复。飞行层仅在视口内绘制，不影响页面滚动。点击入口复用原生分类开合并定位，点击当前黄色入口会收起该分类，不克隆商品或购买处理。只有当前分类的左侧圆钮为黄色，分类标题及其图标背景始终保持白色；仅圆钮的原SVG白底通过局部混色着黄。语言/位面/HUD/重建及Store替换时更新或清理；监听滚动、布局观察和有限动画帧，不新增周期轮询。

自动打开或切换分类时，先将新当前分类纳入原有侧栏成员快照并同步显示其入口，随后在自动置顶和卡片开合期间保持这些成员及工具占位，选中圆钮立即更新为黄色；定位和高度动画结束后，按“当前分类始终保留、其余分类仅离屏”的最终状态统一重新排布，避免标题短暂经过屏幕造成按钮快速往返。手动滚轮、拖动、触摸或滚动键中断后，下一帧恢复按实际可见性更新；快速改选沿用当前侧栏，全部收起、切换样式、重建、HUD退出及Store替换会清理临时状态。原有240ms图标往返、分类组居中及工具受压让位保持。

胶囊分类标题、左侧分类入口和拆解/搬迁，以及两种1.3样式共用的右下两个开关，统一使用ModLoader Tooltip API。鼠标停留600ms显示、键盘焦点即时显示；提示跟随指针并自动避让窗口边缘，现实亮色、虚空暗色，无有效位面时回退Loader主题。类别提示保留Alt+1～7，工具短词与原有类别/开关覆盖20语言，未知语言回退英文；保留ARIA并去掉原生title，避免双重提示。商品卡片只有在“隐藏建筑描述”开启时显示描述提示，两种1.3样式一致；读取真实卡片的当前语言.itemDescription原文，可见的新建筑和不可购买建筑也支持，空描述、隐藏卡片及收起分类不显示。关闭隐藏开关立即停用提示并恢复卡片内描述；保留原购买处理和不可购买判断，不继承父分类提示。

每个控件/卡片通过公共API拥有自己的Tooltip root，模式、语言、位面、描述隐藏开关或可显示状态变化时统一释放一次；其余文案和可用性不变时复用绑定，原生周期刷新不重置600ms延迟；新解锁/替换卡片即时登记，退役卡片释放。原生不可购买卡片仅在隐藏描述开启时恢复鼠标命中，点击仍经原生disabled判断。滚动、点击、分类/代理退出、切样式、语言/位面变化、HUD隐藏/恢复和Store重建/替换时清理或重新登记；Store祖先滚动/滚轮/点击清理后同步登记当前目标，下一次悬停无需等待周期刷新；既有共享portal/主题/边缘与所有权规则由Loader提供，不增加私有提示层、样式或轮询。

只有全部分类收起且鼠标离开整个商店区域连续2秒后，胶囊才同步缩回圆形；重新进入会取消并重新计算延时，展开期间不自动收起。计时使用可取消的单次定时器，没有新增轮询。20种现有语言的类别/开关文案由本入口提供，新语言回退英文；卡片仍使用原生运行时词库。语言重建、位面、HUD和Store对象替换由适配层同步并清理旧控件，商品定位只滚动本容器。

modsch七个常用类别按原生顺序显示：采集、解构、破坏、转换、存储、特殊、其他；其他语言、完成/虚空及按钮文案保持。新增类别名称属于本Mod翻译，不修改原版words、Chinese Optimization或Loader翻译目录。仍复用原生价格/解锁/购买和工具操作，不更改经济规则。现有Tweaks分层Esc和拆解等级图案补丁参与独立共存检查。

## 其他子功能与边界

Save Slots、Language Menu、Settings Page 继续使用各自入口和开关；本次商店实现没有修改这些脚本。多存档停留在用户已确认的阶段。

首批适配仅覆盖桌面商店自身。其他 Mod 的倒计时、扫描控件、创造模式经济和旧商店滚动补丁尚未完成组合验收；恢复经典界面不代表这些功能已适配。移动端不启用经典界面。
