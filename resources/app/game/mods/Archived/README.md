# Archived Mods

This directory stores retired or temporary Mods that should not be discovered
by ModLoader. ModLoader only discovers direct child directories of `mods` that
contain a `mod.json`, while this archive directory has no top-level manifest.

Archived here:

- `SixtyFour_WorldEditer`: frozen legacy World Editor reference.
- `Cattail_Tools_Snapshot-Acceptance`: completed temporary Snapshot API
  acceptance tool.

Move an individual Mod directory back to the direct `mods` directory before
attempting to enable or reuse it.
